# 03 · Exercise · ваша W2 лаба — Grounding, Consent Gate та аудит НБУ

## Learning objective

На практиці реалізувати надійне заземлення (Grounding) та безпечні tool-контракти для кредитного копілота:
1. Оптимізувати пошуковий конвеєр (BM25 + Dense + Cross-Encoder Reranker) для точного знаходження банківських політик.
2. Впровадити обов'язковий **Consent Gate (Шлюз юридичної згоди)** перед викликом зовнішнього Бюро кредитних історій.
3. Забезпечити обов'язкову дисципліну цитування (**Citation Discipline**) для захисту від штрафів регулятора (НБУ).

---

## Бізнес-контекст (Escalation 1 — Аудитор НБУ)

До банку надійшов позаплановий запит від регулятора (НБУ). Інспектори вимагають надати для кожної автоматизованої відмови чи схвалення за останні 180 днів:
* Точні посилання на пункти внутрішніх регламентів або постанов НБУ, на підставі яких ухвалено рішення.
* Доказ того, що банк **не робив запитів до Бюро кредитних історій без зафіксованої письмової згоди клієнта** (порушення закону про захист персональних даних тягне відкликання ліцензії).
* Журнал аудиту з незмінними мітками часу (Audit Trail).

## Якщо застрягли

**Застрягли на логіці Consent Gate?**
Пам'ятайте про правильну послідовність перевірки:
```python
if not consent_id or not consent_id.startswith("consent-"):
    log_audit_event("credit_history_pull", "BLOCKED_NO_CONSENT", {"tax_id": tax_id})
    return {"status": "error", "code": "CONSENT_REQUIRED", "message": "Письмова згода позичальника обов'язкова"}
```

**Чому Cross-Encoder Reranker критичний?**
Векторний пошук ранжує чанки за загальною семантичною схожістю, тому загальний опис кредиту часто має вищий косинусний бал, ніж конкретне правило винятку для ФОП. Cross-Encoder аналізує запит і чанк разом, піднімаючи вузькоспеціалізовані винятки на 1-ше місце.
