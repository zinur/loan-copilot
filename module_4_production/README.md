## Що ви навчитесь

- **Evaluation:** golden dataset для кожного agent'а, offline eval
  (CI gate), online eval (production shadow).
- **Observability:** LangSmith/Langfuse traces, structured logs,
  cost per application.
- **Guardrails:** PII masking (regex + NER), prompt injection detection,
  output refusal patterns.
- **Cost model:** як розрахувати unit economics (grн per application),
  що показати CFO.
